Build a complete, modern and responsive web application called **IdeaVault**.

### PROJECT IDEA

IdeaVault is a student project-idea management and collaboration platform.

The problem:
College students often have good project ideas but forget them, don't know how to organize them, or cannot find other students who are interested in the same idea.

The solution:
IdeaVault allows students to create, save, explore and organize project ideas and find potential teammates.

This should be a real functional web application, not just a landing page.

---

## TECHNOLOGY

Use:

* React
* JavaScript
* CSS
* React Router

Keep the code clean and beginner-friendly.

For the first version, do NOT use an external database or complicated backend.

Use localStorage for storing users, project ideas, saved ideas and basic application data so the application works immediately.

Do not add unnecessary libraries unless they are genuinely needed.
